# @age/shared

Cross-cutting primitives shared by every AGE package and app.

| Folder        | Purpose                          |
| ------------- | -------------------------------- |
| `constants/`  | Application-wide constant values |
| `enums/`      | Shared enumerations              |
| `errors/`     | Base error types                 |
| `interfaces/` | Shared interface contracts       |
| `types/`      | Shared utility types             |
| `utils/`      | Shared pure utilities            |

Scaffold only — all members are placeholders, exported via barrels.
